# personal-finance-dashboard

A beginner-friendly web app for recording income and expenses and viewing spending summaries.

## Planned features

- Add, view, edit, and delete transactions
- Organize transactions by category
- Filter transactions by date and type
- View income, expenses, and balance summaries
- Set budgets and view spending charts
- Import and export transactions as CSV

## Planned technology

- Python and Flask
- SQLite
- HTML, CSS, and JavaScript
- Chart.js

## Project status

In progress. This project is being built step by step.
